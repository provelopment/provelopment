Diese Website ist eine laufende Installation der Open-Source-Vorlage Provelopment Foundation. Der Code, mit dem sie erstellt wurde, ist öffentlich verfügbar und kann heruntergeladen, geändert und in Ihrem eigenen Repository eingesetzt werden.

# Was diese Website zeigt

Dies ist die Referenzinstallation von Foundation, keine Kundenseite. Sie zeigt die wichtigsten Bestandteile, die beim Aufbau einer Foundation-Website zur Verfügung stehen:

- eine Startseite, erstellt mit dem deklarativen JSON-Seitenformat
- diese Seite „Über uns“, erstellt mit Markdown
- gemeinsame Navigation und Website-Konfiguration
- die Darstellungen Seitenleiste und Menüleiste
- ein Layout-Bedienelement, das die Darstellung wechselt, ohne die Seite oder ihren Inhalt zu ändern

Der Zweck ist einfach: Sie können die Vorlage in Aktion sehen, bevor Sie entscheiden, wie Sie sie nutzen oder verändern möchten.

# Eine Website, die Sie steuern

Foundation ist so konzipiert, dass die Website unter der Kontrolle des Betreibers bleibt.

Ihre Seiten, Bilder und sonstigen Website-Inhalte sind Dateien in Ihrem Repository. Verhalten und Einstellungen der Website werden über Konfigurationsdateien definiert. Die Website wird aus diesen Dateien erstellt und liegt nicht in einem geschlossenen Website-Baukasten.

Sie können die Website selbst pflegen, jemand anderen damit beauftragen oder Leistungen von Provelopment nutzen. Die Website selbst bleibt Ihre.

# Zwei Wege, Seiten zu erstellen

Foundation bietet zwei Verfahren zum Erstellen von Seiten.

**Markdown** ist für unkomplizierte Inhalte gedacht. Es bleibt nah am reinen Text, mit einfacher Notation für Überschriften, Listen, Links und Hervorhebungen.

**Deklaratives JSON** ist für Seiten gedacht, die mehr Struktur benötigen. Statt die ganze Seite als Fließtext zu schreiben, definieren Sie Abschnitte wie Heroes, Spalten, Karten, Tabellen und Fragen.

Diese Seite ist das Markdown-Beispiel. Die Startseite ist das JSON-Beispiel.

Beide sind gewöhnliche Seiten. Ihre Dateien bestimmen ihren Inhalt, ihr Speicherort bestimmt ihre Adresse, und veröffentlichte Seiten werden automatisch in die Sitemap der Website aufgenommen.

# Gebaut, um sich anzupassen

Foundation ist darauf ausgelegt, Websites zu unterstützen, die über eine einzelne Seite, eine einzelne Sprache oder einen einzelnen Markt hinauswachsen.

Eine Website kann für mehrere Sprachen, länderspezifische Websites und physische Standorte konfiguriert werden. Besucher können außerdem zwischen den Darstellungen Seitenleiste und Menüleiste wechseln, ohne die Seite zu verlassen.

Diese Referenzinstallation verwendet eine Sprache und keine physischen Standorte, daher wird hier nur das Layout-Bedienelement benötigt. Weitere Bedienelemente erscheinen, wenn die entsprechenden Optionen tatsächlich konfiguriert sind.

# Open Source zuerst

**Foundation ist kostenlos und Open Source: herunterladen, einsetzen, ändern und zu eigen machen.**

Die Nutzung von Provelopment-Leistungen ist optional. Provelopment kann eine Foundation-Website erstellen, erweitern oder pflegen, doch diese Leistungen sind nicht erforderlich, um die Website weiter zu nutzen.

Ihr Repository bleibt die Quelle der Website, sodass Sie sie weiterhin selbst betreiben oder an anderer Stelle einsetzen können.
