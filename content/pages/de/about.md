Diese Seite ist ein Beispiel, das mit der Vorlage Provelopment Foundation
mitgeliefert wird. Alles, was Sie sehen, stammt aus einer Markdown-Datei:
`content/pages/de/about.md`.

## Inhalte bearbeiten

Jede Seite liegt unter `content/pages/<locale>/<slug>.md`. Das Frontmatter
legt den Seitentitel fest, der Rumpf wird als formatiertes Markdown
gerendert:

- **Fett**, _kursiv_ und `Inline-Code`
- [Links](https://example.com) und Listen
- Mehrere Überschriftenebenen

### Seiten hinzufügen

Legen Sie eine neue `.md`-Datei in `content/pages/<locale>/` an, und sie wird
zu einer Seite. Tragen Sie sie in das `navigation`-Array von
`site.config.json` ein, damit Besucher sie finden. Fehlt eine Übersetzung
für eine Sprache, wird automatisch die Version der Standardsprache
ausgeliefert.

Ersetzen Sie diesen Text durch die Geschichte Ihres Unternehmens.
